# 询价文件自动填充

把 Excel 的报价/结算清单数据，自动填进政府采购那一套 Word 模板里。

原来一份项目要手工填 8 个文件、几十处占位，改一次价格要重新对一遍金额大小写。现在改成：**改结算清单 → 跑一次 → 全套文档重新生成**。

## 解决什么问题

政府采购走三方询价，要准备这些材料：

| 序号 | 文件 | 数量 |
|---|---|---|
| 1 | 资格声明 | 每家一份 |
| 2 | 资质材料 | 每家一份 |
| 3 | 报价清单 | 每家一份 |
| 4 | 询价汇总表 | 一份 |
| 5 | 成交通知书 | 一份 |
| 6 | 合同 | 一份 |
| 7 | 签收单 | 一份 |
| 8 | 验收书 | 一份 |

模板里用**红字**标出所有要填的位置（`某某甲方`、`某某公司`、`44650.00` 之类）。手工填的问题：

- 红字容易漏，尤其合同里藏在表格中间的那些
- 金额大小写要手算，改价后容易只改一处
- 换中标方时，八份文件里的公司名、地址、法人全要重填

## 怎么做的

`.docx` 本质是 zip 包，里面是 XML。文字按 **run** 存，每个 run 带自己的格式（颜色、字体、字号）。红色存在 run 的 `<w:color w:val="EE0000"/>` 属性里。

所以替换流程是：

```
读 Excel 建映射  →  扫文档找红色 run  →  合并相邻同色 run  →  查表命中就写值并改黑
```

三个关键点：

**1. 红色系判定用区间，不写死色值**

```python
R >= 0x80 and G <= 0x60 and B <= 0x60
```

项目里同时有 `EE0000`（通知书/验收书/声明）和 `FF0000`（合同）两种红，精确匹配必漏。

**2. run 会分裂**

Word 常把一个词切成多个 run（改过字、复制粘贴都会）。`某某甲方` 可能是 `某某` + `甲方` 两段，单独匹配谁都不中。必须先把**相邻且同色**的 run 合并成逻辑块再查表。

**3. 合并单元格会重复返回**

`table.rows[i].cells` 对合并单元格会返回同一个 `tc` 多次。用 `cell._tc.getroottree().getpath(cell._tc)` 生成 XML 路径去重——不能用 `id()`，lxml 代理对象的 identity 不稳定。

## 目录

```
start.py                    命令行入口：一键跑完
gui.py                      图形界面（tkinter，双击 run_gui.bat）
run_gui.bat                 双击启动 GUI

tools/
  core.py                   公共层：红色判定 / 文档遍历 / 映射加载 / 替换引擎
  fillers.py                各文档的填充器
  sync_quote_table.py       报价明细 → 文档表格同步（行数自动增删）
  doc2docx.py               老 .doc → .docx（Word COM）
  scan_red.py               扫描红字，输出位置 + 上下文
  inspect_docx.py           文档体检：段落 / 表格矩阵 / 颜色分布
  build_sample_data.py      生成示例数据
  build_red_info.py         生成红字信息表
  build_license.py          生成营业执照占位页
  build_qualification.py    生成资质信息核查表
```

## 安装

需要 Windows + Microsoft Word（`.doc` 转换走 COM，所以必须装 Word）。

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 使用

**图形界面**：双击 `run_gui.bat`，选结算清单 → 选中标方 → 填甲方信息 → 开始生成。

**命令行**：

```bash
python start.py          # 全量
python start.py --dry    # 只检查前置文件
```

输出全部是新文件（`_已填` 后缀 / `已填/` 目录），**源文件一个字节都不动**。

## 数据从哪来

| 数据 | 来源 |
|---|---|
| 金额、明细行 | `9、结算清单 价格.xlsx` |
| 乙方信息（名称/地址/联系人/电话/法人/信用代码） | `红字信息/{公司名}.xlsx` |
| 甲方信息（校名/项目名/地址） | `红字信息/甲方.xlsx` + 界面输入 |

**金额的唯一来源是结算清单**。红字信息表里的金额字段只当「占位匹配用」，值会被结算清单覆盖——这样改价只要改一个 Excel。

## 已知限制

- 只处理红色系标记，**黑字占位一律不碰**（模板作者有意留白的签字栏）
- 表格结构大改（加列、换表头）时，`sync_quote_table` 会认不出来直接跳过，不会瞎改
- 上传的 Excel **不需要任何颜色标记**，按表头文字定位列
